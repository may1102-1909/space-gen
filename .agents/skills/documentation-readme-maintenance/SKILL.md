# Documentation Readme Maintenance

Use this skill when setup, behavior, architecture, APIs, or developer workflows change.
1. Locate the current canonical documentation and avoid duplicating it elsewhere.
2. Update only the sections affected by the change.
3. Verify commands, paths, environment variable names, and version assumptions.
4. Use placeholders for secrets and explain how to obtain required configuration.
5. Distinguish tested commands from illustrative examples.
6. Keep documentation proportional to the feature; do not create extra docs without value.
