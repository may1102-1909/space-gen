# Playwright Job Automation

Use this skill for job discovery, form filling, browser testing, or approved web automation.
1. Inspect site terms, allowed automation boundaries, and required user approvals.
2. Prefer stable selectors, explicit waits, and resumable checkpoints.
3. Keep user profile data and credentials protected.
4. Require human confirmation before submitting consequential applications or messages unless the user explicitly authorized that exact action.
5. Use bounded retries, deduplication, and idempotency where possible.
6. Respect rate limits, robots/anti-abuse controls, and site restrictions; do not bypass access controls.
7. Record what was attempted and whether submission was confirmed.
