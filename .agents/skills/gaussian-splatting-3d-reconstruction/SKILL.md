# Gaussian Splatting 3D Reconstruction

Use this skill for Gaussian splatting pipelines, scene reconstruction, or viewer performance.
1. Inspect the capture/processing pipeline, file sizes, viewer implementation, and target hardware.
2. Identify bottlenecks in reconstruction time, memory, network delivery, and rendering.
3. Preserve a known-good source asset before destructive optimization.
4. Measure quality and performance using consistent scenes and camera paths.
5. Optimize streaming, level of detail, culling, and asset loading where supported.
6. Check browser/GPU compatibility and graceful fallback.
7. Report trade-offs in visual fidelity, load time, and memory.
