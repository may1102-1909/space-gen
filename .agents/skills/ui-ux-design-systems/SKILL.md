# Ui Ux Design Systems

Use this skill for new UI, visual polish, design systems, or component consistency.
1. Inspect existing tokens, typography, spacing, colors, components, and responsive patterns.
2. Reuse design tokens instead of introducing near-duplicate values.
3. Preserve hierarchy, contrast, focus states, keyboard access, and semantic HTML.
4. Consider empty/loading/error states and long content.
5. Avoid gratuitous animation, decoration, or inconsistent one-off components.
6. Verify the actual UI at relevant breakpoints when browser tools are available.
7. Report visual limitations if no screenshot/browser verification was possible.
