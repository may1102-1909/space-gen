# Rag Knowledge Retrieval

Use this skill for document search, RAG, project knowledge bases, or semantic memory.
1. Identify the knowledge source and freshness requirements.
2. Chunk and index content with useful metadata and access boundaries.
3. Retrieve a small relevant set; use reranking only when it improves measured results.
4. Preserve source references and distinguish evidence from inference.
5. Handle stale, conflicting, missing, or unauthorized content explicitly.
6. Evaluate retrieval precision and answer grounding with representative queries.
7. Avoid storing secrets or sensitive data without a justified, approved design.
