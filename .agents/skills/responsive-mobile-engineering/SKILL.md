# Responsive Mobile Engineering

Use this skill for mobile layouts, responsive bugs, or cross-device browser behavior.
1. Inspect current breakpoints and responsive conventions.
2. Test narrow, medium, and wide viewports relevant to the page.
3. Check overflow, tap targets, keyboard behavior, orientation, and long text.
4. Consider network latency, asset weight, and device performance.
5. Avoid fixed dimensions where content needs to adapt.
6. Verify critical interactions on a real browser/device when available.
