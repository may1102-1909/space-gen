# scene-agent-skills

20 skills vendored in this pack. Read the single `SKILL.md` whose description matches the task.

- `scene-archicad-bridge/SKILL.md` — Bring a validated IFC reconstruction into Archicad and inspect element inventory using the documented Python connection when available.
- `scene-asset-pipeline/SKILL.md` — Validate architectural textures and asset dependencies, prepare licensed resources and prevent missing or ambiguous file references.
- `scene-batch-variants/SKILL.md` — Plan and execute controlled architectural style, lighting or camera variants with shared geometry and comparable render settings.
- `scene-camera-match/SKILL.md` — Match architectural perspective to reference landmarks or transfer a solved camera to Corona; use for camera calibration and perspective discrepancies.
- `scene-corona-lightmix/SKILL.md` — Create or review organized Corona LightMix groups without deleting existing render elements or silently changing the lighting balance.
- `scene-corona-materials/SKILL.md` — Create or correct Corona Physical Materials, texture scale, roughness, glass and displacement in architectural scenes.
- `scene-corona-setup/SKILL.md` — Configure an existing 3ds Max scene for Corona preview, review or final rendering, with explicit renderer capability checks.
- `scene-delivery-package/SKILL.md` — Package an architectural scene with dependencies, cameras, render settings, provenance and a reproducible reopening checklist.
- `scene-exterior-landscape/SKILL.md` — Build architectural exteriors with realistic grass, trees, terrain and water while retaining camera accuracy and manageable scene performance.
- `scene-interior-build/SKILL.md` — Reconstruct an architectural interior from images or plans, including furniture, glazing, circulation, materials and visible lighting.
- `scene-lighting-atmosphere/SKILL.md` — Reconstruct architectural daylight, dusk, night or interior illumination and atmospheric depth from a reference.
- `scene-model-high/SKILL.md` — Build production architectural geometry and furniture with physical bevels, clean normals, controlled subdivision and suitable UV density.
- `scene-model-low/SKILL.md` — Build or simplify architectural assets for blockout, realtime review or a low-poly deliverable with explicit silhouette and draw-call constraints.
- `scene-model-ultra/SKILL.md` — Increase detail for architectural hero closeups when a production model fails a defined silhouette, surface or displacement target.
- `scene-plan-to-bim/SKILL.md` — Convert a dimensioned or traced floor plan into validated structured geometry and an IFC4 model with walls, slabs, doors, windows and openings.
- `scene-reference-analysis/SKILL.md` — Analyze architectural photos, renders and drawings into geometry, material, camera and uncertainty observations before reconstruction.
- `scene-render-review/SKILL.md` — Compare an architectural render with its references and prioritize camera, geometry, material, lighting and foliage corrections.
- `scene-style-transfer/SKILL.md` — Restyle an architectural image or existing scene using one of 16 render, design and presentation recipes while preserving requested geometry.
- `scene-toolkit/SKILL.md` — Route an architectural image, render or plan task to a concrete scene workflow; use when the request spans reference analysis, modeling, rendering or BIM.
- `scene-topology-audit/SKILL.md` — Inspect architectural mesh topology, UVs, scale, openings and spatial relationships before rendering or delivery.
