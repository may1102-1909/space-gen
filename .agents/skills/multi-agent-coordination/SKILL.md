# Multi Agent Coordination

Use this skill when multiple agents may help with a task.
1. Decide whether parallelism will save time after accounting for coordination cost.
2. Split work by independent deliverable and file ownership.
3. Give each agent bounded scope, inputs, expected outputs, and acceptance criteria.
4. Use separate branches/worktrees for concurrent edits.
5. Avoid duplicate research and shared mutable state.
6. Have a lead agent integrate, review, and run final tests.
7. Stop redundant agents and summarize unresolved disagreements.
