# Llm Ai Application Engineering

Use this skill for model APIs, structured output, tool use, latency, and AI product features.
1. Define task success, latency, privacy, and cost requirements.
2. Use structured schemas and validate model outputs before side effects.
3. Keep prompts concise and separate stable instructions from task-specific data.
4. Handle timeouts, rate limits, refusals, partial output, and model changes.
5. Use eval cases for representative success and failure modes.
6. Avoid sending unnecessary private data or large context.
7. Measure quality and cost before switching models or adding agents.
