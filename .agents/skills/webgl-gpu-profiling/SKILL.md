# Webgl Gpu Profiling

Use this skill when 3D performance, shader cost, frame drops, or GPU memory is the problem.
1. Establish a reproducible scene, device, viewport, and performance baseline.
2. Measure frame time, draw calls, triangles, texture memory, shader complexity, and CPU/GPU symptoms where tooling allows.
3. Change one major factor at a time.
4. Prefer evidence-driven reductions in overdraw, shader work, texture size, and geometry.
5. Re-test quality and behavior after optimization.
6. Do not claim a performance gain without comparable measurements.
