# Recommendation Personalization

Use this skill for recommendations, ranking, personalization, or feed ordering.
1. Define the user outcome and measurable evaluation metric.
2. Start with a simple baseline before adding complex models.
3. Separate candidate generation, ranking, filtering, and presentation.
4. Minimize personal data and provide controls where appropriate.
5. Evaluate relevance, diversity, cold-start behavior, and unintended feedback loops.
6. Avoid leaking one user's private activity to another.
7. Compare against a baseline and document limitations.
