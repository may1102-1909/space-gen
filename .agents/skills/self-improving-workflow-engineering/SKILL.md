# Self Improving Workflow Engineering

Use this skill after repeated failures or when a workflow can be made reliably repeatable.
1. Review concrete failure evidence and the accepted fix.
2. Determine whether the lesson generalizes beyond one task.
3. Prefer a small script, test, checklist, or focused skill over expanding global instructions.
4. Add a trigger description and clear success criteria.
5. Test the workflow on a representative case before adoption.
6. Propose global or self-modifying changes for review; never silently weaken safety rules.
7. Remove obsolete instructions when they create duplication or conflict.
