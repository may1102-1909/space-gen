# Api Backend Engineering

Use this skill for REST/GraphQL endpoints, server handlers, workers, or service integrations.
1. Inspect existing API conventions and versioning before adding endpoints.
2. Validate inputs and enforce authorization on the server.
3. Define predictable success/error shapes and appropriate status codes.
4. Add timeouts, bounded retries, idempotency, and pagination where relevant.
5. Avoid leaking stack traces, secrets, or internal data to clients.
6. Add tests for validation, authorization, failure cases, and normal behavior.
7. Update API docs only where behavior or contracts changed.
