# Typescript Javascript Engineering

Use this skill for JS/TS code, Node.js, browser code, or package configuration.
1. Follow the existing runtime, module system, formatting, and lint conventions.
2. Prefer strict types and narrow interfaces; avoid `any` unless justified and contained.
3. Handle async errors, cancellation/timeouts, and resource cleanup explicitly.
4. Validate untrusted input at system boundaries.
5. Avoid needless dependencies and incompatible package upgrades.
6. Check the relevant typecheck, lint, and tests; confirm module configuration matches import syntax.
7. Do not print secrets or sensitive payloads in logs.
