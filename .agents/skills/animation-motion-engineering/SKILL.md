# Animation Motion Engineering

Use this skill for transitions, scroll effects, canvas animation, or motion design.
1. Follow the existing animation library and motion language.
2. Prefer transform/opacity animations where suitable; avoid repeated layout thrashing.
3. Clean up observers, listeners, animation frames, and subscriptions.
4. Respect reduced-motion preferences and provide usable fallbacks.
5. Avoid excessive scroll handlers and unnecessary state updates.
6. Verify smoothness and interaction on target devices where possible.
