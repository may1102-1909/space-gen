# Git Safe Change Management

Use this skill before substantial edits, parallel work, rebases, merges, or cleanup.
1. Inspect branch, status, diff, and untracked files before changing anything.
2. Preserve user changes; never discard or reset them without explicit approval.
3. Keep changes scoped and reviewable.
4. Use branches/worktrees for independent parallel tasks.
5. Avoid force pushes, destructive resets, and history rewrites unless explicitly approved.
6. Review staged and unstaged diffs before committing.
7. Report branch and commit status accurately.
