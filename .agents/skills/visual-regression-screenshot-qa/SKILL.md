# Visual Regression Screenshot Qa

Use this skill when a UI change could alter layout, typography, rendering, or responsive behavior.
1. Identify the canonical pages, viewports, and states to compare.
2. Use consistent viewport, data, fonts, and rendering conditions.
3. Compare screenshots or snapshots and investigate meaningful differences.
4. Distinguish intentional design changes from regressions.
5. Check accessibility and interaction behavior as well as pixels.
6. If screenshot tooling is unavailable, state the limitation rather than claiming visual verification.
