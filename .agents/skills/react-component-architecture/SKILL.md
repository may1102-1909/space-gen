# React Component Architecture

Use this skill for React, Next.js, or related component work.
1. Follow the repository's framework, routing, and data-fetching patterns.
2. Keep components cohesive and state as local as practical.
3. Handle loading, empty, error, and success states.
4. Avoid unnecessary effects, duplicate derived state, and avoidable rerenders.
5. Preserve accessibility semantics and keyboard interactions.
6. Add component or integration tests for meaningful behavior.
7. Check lint, typecheck, and production build as appropriate.
