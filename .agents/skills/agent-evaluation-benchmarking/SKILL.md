# Agent Evaluation Benchmarking

Use this skill when building or improving agents, prompts, skills, or multi-agent workflows.
1. Define representative tasks, success criteria, and failure categories.
2. Establish a baseline before changing the workflow.
3. Measure task success, regression rate, wall-clock time, tool calls, and token/cost data when available.
4. Include edge cases, ambiguous requests, and safety boundaries.
5. Compare runs under similar conditions; account for variance.
6. Keep evaluation data reproducible and avoid leaking private data.
7. Do not claim improvement without measured evidence.
