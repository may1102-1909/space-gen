# Session Handoff Checkpointing

Use this skill before a planned handoff, context reset, interruption, or end of a long task.
1. Update the repository's existing task tracker if present.
2. Record goal, current milestone, completed work, exact changed paths, and verification commands/results.
3. Record blockers, assumptions, unresolved decisions, and the next concrete action.
4. Include only the context needed to resume; do not paste entire chat logs or terminal output.
5. State whether changes are committed, uncommitted, or isolated in a worktree.
6. Do not claim a checkpoint persists unless it was actually written to a file or task system.
