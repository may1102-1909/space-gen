# Web Performance Core Vitals

Use this skill for slow startup, large bundles, poor responsiveness, or Core Web Vitals.
1. Measure a reproducible baseline with available browser/build tools.
2. Identify whether the bottleneck is network, JavaScript, rendering, images, fonts, or backend latency.
3. Optimize the largest proven bottleneck first.
4. Use lazy loading, code splitting, caching, and responsive assets when appropriate.
5. Avoid premature micro-optimization and unnecessary dependencies.
6. Re-measure under comparable conditions and report actual results.
