# Database Supabase Engineering

Use this skill for schemas, SQL, migrations, Supabase, indexes, policies, or data access.
1. Inspect current schema, migrations, query patterns, and access policies.
2. Prefer additive, reversible migrations; assess existing data and rollout compatibility.
3. Enforce authorization with database policies where applicable, not only frontend checks.
4. Review indexes and query plans when performance is a concern.
5. Test migration behavior and policy access for allowed and denied users.
6. Never run destructive production migrations without explicit authorization and a recovery plan.
7. Keep credentials out of source control and logs.
