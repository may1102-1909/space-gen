# 3D Asset Glb Optimization

Use this skill for large 3D models, mobile loading, GLB pipelines, or texture/mesh optimization.
1. Inspect asset size, mesh count, texture dimensions, materials, animation, and target devices.
2. Establish quality and loading baselines before compression.
3. Choose mesh/texture compression compatible with the actual runtime and hosting pipeline.
4. Preserve UVs, normals, materials, animation, and transparency requirements.
5. Test decoder availability and fallback behavior.
6. Compare visual quality and loading/performance after each change; retain originals until verified.
