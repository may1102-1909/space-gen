# Technical Research Source Verification

Use this skill when behavior depends on current APIs, package versions, licensing, or platform support.
1. Prefer official documentation, release notes, source repositories, and primary specifications.
2. Check the installed version and whether the source applies to it.
3. Distinguish confirmed behavior from inference and community workarounds.
4. Verify licenses and maintenance status before recommending dependencies.
5. Cite sources for claims that may change over time.
6. Avoid broad research when local code or existing docs already answer the question.
7. Summarize only the facts needed for the implementation decision.
