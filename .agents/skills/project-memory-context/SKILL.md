# Project Memory Context

Use this skill when starting work in an unfamiliar repository, resuming a project, or updating durable project knowledge.
1. Inspect the relevant AGENTS.md files and current Git status.
2. Read only the docs relevant to the task; do not dump the whole repository into context.
3. Separate durable facts (architecture, conventions, constraints) from temporary task progress.
4. Update the existing source of truth rather than creating duplicate memory files.
5. Keep notes short, dated when time-sensitive, and linked to evidence such as file paths or test commands.
6. Never store secrets, tokens, credentials, or unnecessary personal data.
7. Before finishing, record only decisions or discoveries that will likely help future tasks.
