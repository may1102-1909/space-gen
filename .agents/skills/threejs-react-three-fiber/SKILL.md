# Threejs React Three Fiber

Use this skill for 3D web scenes, R3F components, materials, interactions, or rendering issues.
1. Inspect the scene graph, renderer setup, asset pipeline, and current performance before changing code.
2. Reduce unnecessary draw calls, material variants, geometry duplication, and per-frame allocations.
3. Reuse geometries/materials where safe and dispose of resources when no longer needed.
4. Avoid React state updates on every animation frame; use refs or frame-loop patterns appropriately.
5. Respect reduced-motion and mobile GPU constraints.
6. Verify visual correctness and profile frame time on target hardware when possible.
